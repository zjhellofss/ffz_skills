# 本地评分指标口径

## 1. 可直接计算

脚本从本地结构化数据计算：

- 营收 YoY、三年 CAGR；
- 扣非归母净利润 YoY、可用时的三年 CAGR；
- 合并毛利率、归母净利率、披露加权归母 ROE；
- 三年累计 OCF/归母净利润，历史不足时才回退当前 FY；
- 长期资产现金支出口径 FCF/营收；
- 销售收现/营业收入；
- 资产负债率、流动比率、严格净现金/总资产；
- 扣非/归母利润、研发费用强度；
- 有明确商誉数值时的商誉/归母权益；
- OCF、存货周转天数变化、折旧摊销/营收；
- 审计意见风险；
- 杜邦三因子及少数股东权益影响。

百分比输入百分点数；ratio 输入倍率。所有计算使用 `Decimal`。

## 2. 特殊状态

- 三年 CAGR 必须有四个完整 FY，且窗口数值均为正。
- 扣非利润由非正转正用 `turnaround`，由正转非正用 `turn_loss`。
- 三年现金转换使用当前 FY 及前两个 FY 的累计 OCF/累计归母净利润。
- 单年现金转换只在三年历史不足且三年项明确为 `missing:insufficient_history` 时提供。
- 非正分母使用受控 `not_meaningful`，不生成异常百分比。

## 3. 本地数据不充分的指标

默认保持缺失：

| 指标 | 原因 |
|---|---|
| `government_grant_pnl_ratio` | 没有可防重复的补助当期损益明细 |
| `rd_capitalization_rate` | 期末研发资产不等于当期资本化投入 |
| 客户/供应商最大及前五占比 | 主营构成不是交易对手集中度 |
| `performance_commitment_flag` | 没有履约核查数据 |
| `debt_default` | 没有债务违约核查数据 |
| `impairment_to_pbt` | provider 减值列存在符号及重叠口径问题 |

这些缺口必须进入覆盖率和结构筛查门控。不得用 `not_applicable` 缩小分母。

## 4. 净现金口径

```text
net_cash_to_assets
= (期末现金及现金等价物 - 财务指标中的带息债务) / 资产总计
```

不加入交易性金融资产、理财或受限货币资金。带息债务是本地 provider 的结构化指标；报告中明确这一来源约束。

## 5. 审计风险

`标准无保留意见` 映射为 `checked_clear/0`；其他审计结果映射为 `triggered/1`。没有审计意见时为 `missing`，不能自动清除风险。

## 6. 季度诊断口径

使用 `--period YYYYQ1/YYYYQ2/YYYYQ3`：

- `rev_growth/nps_growth`：当前累计同比上年同期累计；
- 毛利率、净利率、FCF、收现比、研发强度：使用 TTM 流量；
- 三年 CAGR：锚定最近完整 FY；
- 三年现金转换：最近三个完整 FY；
- 资产负债率、流动比率、净现金率、商誉占比：季度末；
- 存货周转天数变化：当前季度对比上年同季度；
- 披露加权 ROE：没有可比 TTM 披露值时保持缺失；
- 扣非利润或折旧摊销季度字段为空时，对应 TTM 指标保持缺失。

季度结果强制为 `QUARTERLY_DIAGNOSTIC / N/R`，不进入正式评级和排名。年度规则分档只用于诊断映射，不能声称季度结果具有年度审计评级效力。

同业默认 `peer_group=<subsector>-cn-a`。多家公司用 `scripts/score_cohort.py` 合并同一 peer_group 后再调用共享 `score.py`。不要把 PDF 年报 facts 或飞书横比分数并入本路径。
