# 半导体基本面对比

仅把用户提供的飞书目录文档及其可访问的报告子文档作为事实来源。`caiwu-fenxi` 是报告口径与行业判断框架；本技能负责把已有的公司报告转成可比、可审计的横向结论。

本 skill **不是** `jibenmian-pingfen` 的下游。不要读取 `facts.csv`、`score_summary.csv` 或本地财务 CSV；也不要把这里的 0–100 表现分、模型调整后综合排序写成 A/B+/B 或 `FORMAL`。用户若要规则评级，应回到年报 PDF 走 `caiwu-fenxi` → `jibenmian-pingfen`，或走 `jibenmian-pingfen-local-data`。

## 读取边界

- 将输入视为飞书 Docx/Wiki 目录 URL 或 token。用 `lark-doc` 读取；执行前遵守其前置要求，先读取 `lark-shared/SKILL.md` 与 `lark-doc/references/lark-doc-fetch.md`，并以 `--as user` 访问用户资料。
- 先读取目录全文或目录结构，提取每家公司名称、报告标题、文档 URL/token，以及报告期。仅跟随目录中明确列出的飞书文档、其正文中的明确飞书文档引用，或可从嵌入引用中取得的飞书文档 token。
- 用 `docs +fetch --doc <URL或token> --doc-format markdown --detail with-ids` 读取每份报告；对长文档先取 outline，再按章节读取。保留文档标题、token、revision_id、章节名和 block id。
- 不读取本地文件，不下载或解析本地附件，不搜索云盘、互联网、市场数据库、新闻或原始财报，也不以模型记忆补充任何数据。技能内置的评分方法不是事实来源。
- 若目录未给出可访问的公司报告、报告链接失效、无读取权限，或子文档不是飞书文档，列为“未纳入”，说明原因并请用户补充飞书链接；不得用其他来源替代。
- 若目录包含报告以外的材料，只在它也是目录明确列出的飞书文档时使用，并在来源表标注材料类型。不要把报告的结论当作未被其引用数据支持的事实。

## 工作流程

1. 建立来源清单。记录每家公司、报告文档、报告覆盖期间、币种、会计口径、主要半导体子赛道、文档 revision，以及可访问性。阅读 `caiwu-fenxi` 的半导体口径，按设计/Fabless、IDM、晶圆代工、封测、设备、材料、EDA/IP 等分类；多业务公司可多标签，但指定收入或主要业务对应的主赛道。
2. 先做可比性检查。确认比较期间、财年、币种、合并范围、会计口径、一次性事项和业务边界。不得把不同财年硬对齐，不得汇率换算或补算未披露的数值。将公司分成同赛道可比组，并单列跨赛道组。
3. 建立证据台账。对每一个进入评分、排名或结论的数字和判断，记录原始指标名、数值、单位、期间、同比/环比基期、计算公式（如有）、来源文档标题、章节/表格及 block 直链。只在原始数值齐全时计算比率；计算值必须标注“计算值”。
4. 按 `references/ranking-framework.md` 评分。先给出同赛道排名，再给出跨赛道的“模型调整后综合排序”。后者用于阅读排序，不能表述为经营模式完全相同的业绩排名。没有达到最低证据覆盖率的公司不进入正式名次。
5. 写报告。先呈现可比性和数据覆盖限制，再呈现数据表、评分表、排名和公司/组合结论。每一条材料性结论后都附飞书来源；区分“来源披露”“计算值”和“分析判断”。

## 证据与计算规则

- 优先使用各公司报告中覆盖最新可比期间的数值。报告期不同但仍可比较时，在表头写明各自起止日；不能比较时保留数据但不横向评分。
- 保留原币种和原单位。跨公司评分优先用增长率、利润率、现金转换、杠杆、周转趋势等比率；不得因收入金额更大而额外加分。
- 仅在分子、分母、期间和单位均可追溯时计算：同比增速、毛利率/净利率变动、经营现金流/净利润、自由现金流、净现金、存货或应收款变动等。分母为零、期间不一致或口径不一致时写“不适用”。
- 任何管理层原因、产品量产/验证、订单、客户集中度、库存跌价、减值、诉讼、关联交易或融资风险，都必须能在飞书报告中定位。没有披露不等于不存在；将其记为“未披露/未评分”。
- 不使用股票价格、估值、分析师预测、买卖建议或目标价。输出不是投资建议。

## 排名呈现

- 同赛道可比组：展示名次、综合表现分、证据覆盖率、排名置信度及每项得分依据。组内少于 3 家时标注“小样本”。
- 跨赛道综合排序：仅在所有入选公司达到最低覆盖率且每个核心维度至少有一项可评分证据时生成。标题必须含“模型调整后”；同时保留主赛道，禁止把设备/材料的交付或产能指标与 Fabless/IDM 的收入、毛利率或资本开支直接比较。
- 无正式名次：覆盖率不足、期间不可比、主赛道无法判断或关键结论不能定位来源时，放入“数据不足/不可比”表，不分配排名或虚构总分。
- 并列时按更高的证据覆盖率排序；若仍相同则并列，不用未经披露的数据打破并列。

## 输出格式

按以下顺序输出中文报告；用户明确要求写入飞书文档时，再按 `lark-doc` 的写入规范创建或更新文档。

1. 比较范围与唯一来源说明（目录文档和纳入报告清单）
2. 可比性、期间和排除项
3. 可追溯数据台账（每行至少含公司、指标、期间、值/单位、类型、飞书来源）
4. 评分方法、证据覆盖率与置信度说明
5. 同赛道排名与模型调整后综合排序（如满足条件）
6. 公司逐项比较：增长与盈利、现金与资产负债、商业化/执行、主要风险
7. 横向结论：领先项、分化来源、共同风险和需要补充的数据
8. 限制与未评分项

来源采用以下紧凑格式，并给出可点击的飞书文档或 block 链接：`【来源：<公司>，《<报告标题>》— <章节/表格>，<期间>】`。一个段落有多个来源时逐一列出；没有来源的事实性句子删除或改写为限制说明。

详细的分数、覆盖率、分组和结论模板见 [ranking-framework.md](references/ranking-framework.md)。
