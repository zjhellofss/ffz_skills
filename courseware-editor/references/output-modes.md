# Output Modes

Use this reference when the user asks for a specific teaching format.

## Slide Text

- Compress to the minimum wording that still preserves meaning.
- Prefer short lines over full paragraphs.
- Remove filler phrases such as "we can see that" or "it should be noted that".
- Keep one core idea per bullet or sentence.

## Lecture Narration

- Write as if the instructor is speaking continuously.
- Add light transitions only when they help listeners track the explanation.
- Prefer natural spoken wording over formal written style.

## Handout or Notes

- Keep complete sentences and enough context for standalone reading.
- Add short clarifications when the original wording assumes too much prior context.
- Preserve definitions and conditions explicitly.

## Outline

- Reduce content to a teaching sequence.
- Order items from concept to mechanism to example when possible.
- Keep bullets parallel in structure.
