# 用例：示例设备公司严格评分

本例演示 v2 事实账本 → 评分映射 → 明细/汇总/manifest。数据是规则演示，不代表真实公司。

## 1. 输入与校验

- 评分映射：`assets/example-input.csv`
- 事实账本：`assets/example-facts.csv`
- 可核验来源：`assets/example-source.txt`
- 口径：FY2025、审计、合并报表、设备类、纯半导体业务

运行：

```bash
python3 scripts/score.py assets/example-input.csv \
  --mode strict \
  --facts assets/example-facts.csv \
  --source-root assets \
  --out-dir /tmp/example-score
```

严格模式先调用 `caiwu-fenxi` 事实校验器。任一 fact ID、公式、单位、期间、审计状态、文件或 locator 不合规时，不得生成正式评级。

## 2. 子指标得分

| 维度 | 子指标 | 原始值 | 命中档 | 分 |
|---|---|---:|---|---:|
| D1 | 营收增速 | 71.68% | ≥40 | 5 |
| D1 | 扣非增速 | 152.52% | ≥50 | 5 |
| D2 | 合并总毛利率 | 52.21% | ≥45 | 5 |
| D2 | 归母净利率 | 25.28% | ≥25 | 5 |
| D2 | 披露加权 ROE | 12.22% | [12,18) | 4 |
| D3 | 当前 FY OCF/归母净利 | 0.72 | [0.60,0.90) | 3 |
| D3 | 长期资产口径 FCF/营收 | 2.40% | [2,8) | 3 |
| D3 | 收现比 | 0.726 | [0.70,0.85) | 2 |
| D4 | 资产负债率 | 24.9% | ≤25 | 5 |
| D4 | 流动比率 | 3.23 | ≥2.50 | 5 |
| D4 | 严格净现金/总资产 | 18.0% | [15,30) | 4 |
| D5 | 扣非/归母 | 0.966 | ≥0.90 | 5 |
| D5 | 已对账政府补助/利润总额 | 5.5% | ≤10 | 5 |
| D5 | 研发资本化率 | 0% | =0 | 5 |
| D6 | 研发费用强度 | 8.55% | [8,12) | 4 |

规则 v2.1 起 D6 只保留研发费用强度。前五大直接客户占比(58.28%)和前五大供应商占比(41.34%)不再计入正分,改作预警项:两者均未超过 60% 阈值,故预警状态为 `cleared`(见 §4)。

三年营收 CAGR 和三年扣非 CAGR 明确记为 `missing:insufficient_history`。三年现金转换也因历史不足而明确缺失，所以允许回退当前 FY；这不是 N/M 或结果不佳时的择优切换。

## 3. 维度分与加权

- D1 = 5.00
- D2 = 4.67
- D3 = 2.67
- D4 = 4.67
- D5 = 5.00
- D6 = 4.00

设备权重(规则 v2.2)为 `22/20/18/14/19/7`，Decimal `ROUND_HALF_UP` 计算得到原始分 **4.40**。(v2.2 将设备 D6 权重由 12 降为 7、回补 D1/D2/D5,总分从 v2.1 的 4.36 微升至 4.40;权重从最弱的 D6=4.00 挪向更强维度,方向合理。)

## 4. 覆盖率与结构筛查

- 15/17 个核心槽位已评分(两项三年 CAGR 为 `missing`),原始覆盖率 **88.2%**。
- 15 个已评分槽位全部通过 fact ID、FY、审计、口径和来源校验；已评分证据覆盖率 **100%**。
- 六项结构性风险均有事实支持且未触发；结构筛查覆盖率 **100%**。
- 六项预警中演示了 OCF 及前五客户/供应商两项(均 `cleared`),预警筛查覆盖率为 50%；预警缺失不被表述为“无风险”。

## 5. 结论与产物

结果是 **4.40 / FORMAL / A / 高置信度**。单一公司同业池不显示“第 1 名”。

输出目录包含：

- `score_summary.csv`：维度分、四类覆盖率、资格状态、扣分和排名；
- `score_detail.csv`：17 个核心槽位及结构/预警逐项值、命中档、分数、fact ID、公式与来源；
- `ranking.csv`：仅正式同业 cohort；
- `score_manifest.json`：规则、引擎、输入和产物哈希；
- `score_inputs.snapshot.csv`、`facts.snapshot.csv`：本次运行的不可混淆输入快照。

若只运行兼容模式，同样得到诊断分 4.40，但发布评级必须是 `N/R`，不能把 `diagnostic_grade=A` 写成正式 A。
