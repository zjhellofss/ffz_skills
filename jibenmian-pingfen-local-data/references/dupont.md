# 本地数据 ROE 杜邦分解

## 公式

```text
归母净利率 = 归母净利润 / 营业收入
总资产周转率 = 营业收入 / 平均总资产
归母权益乘数 = 平均总资产 / 平均归母权益
三因子 ROE = 上述三项乘积
```

平均值使用当前 FY 与前一 FY 年末时点。与本地财务指标数据中的披露加权归母 ROE 对账：

- 绝对差不超过 1.00 个百分点：`matched`
- 大于 1.00 且不超过 2.00：`review`
- 大于 2.00：`explain`

差异通常来自简单期初/期末平均与监管加权净资产口径不同，不自动表示数据错误。

## 运行

仅完整 FY 支持杜邦分解。在年度一键评分命令加 `--with-dupont`。脚本用同一份 `local-facts.csv` 生成：

- `dupont/dupont.csv`
- `dupont/dupont_manifest.json`
- 输入和事实快照

金额事实必须同公司、同合并范围、同币种并为已审计状态；期初/期末事实必须来自相邻 FY 年末。

季度诊断不接受 `--with-dupont`。本地季度数据没有可直接与 TTM 三因子 ROE 对账的披露加权 TTM ROE；不要用季度累计 ROE 或简单年化值冒充。

## 少数股东权益

同时计算总权益乘数、总权益 ROE、平均少数股东权益及其占比。少数股东权益占平均总权益绝对值至少 20% 时标记 `major_nci_flag=true`；这是分析预警阈值，不是会计准则。

当归母权益乘数明显高于总权益乘数时，不把全部放大解释为债务杠杆。当合并净利润为负而归母净利润为正时，必须同时展示总权益 ROE，不用归母 ROE 掩盖集团整体亏损。
