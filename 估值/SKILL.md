# 科技股估值分析

## 定位与硬边界

**核心思想：先判断"公司未来能创造多少价值"，再判断"市场现在要求你支付多少价格"。看懂公司 ≠ 价格便宜；好公司 + 过贵价格 = 差收益。**

把估值结论称为**分析判断**，不称为预测或保证。高分/低估值不等于"该买"，高估值不等于"该卖"；不输出单一价格目标作为指令，只输出**合理价格区间(三情景)**与**安全边际内的买入参考区间**。任何估值都明确声明：不构成投资建议。

严格区分：

- `公司披露事实`：来自财报或 `caiwu-fenxi` / `jibenmian-pingfen` 事实账本；
- `计算指标`：有公式和输入，可复算(PE、PEG、EV/Sales、FCF yield、三维分等)；
- `预测假设`：收入增长、利润率、折现率等——必须标明依据与敏感度，**不得伪装成事实**；
- `分析判断`：质量评估、预期差、合理价格区间、安全边际。

**铁律**：估值数字的可靠性只取决于假设的可靠性。任何假设都要能回答"为什么"，不能接受"公司变优秀所以利润提高"这类循环论证。

## 工作流

### 1. 确认输入与投资假设

为每个标的确认：

- 公司、行业/子行业(半导体按 `jibenmian-pingfen` 的子行业分类)、币种、期间；
- **投资假设**：投资周期、核心逻辑(行业增长/市占率提升/利润率改善/新产品周期)、最大风险。写不出 3 句话就别进入估值。

### 2. 判断公司质量(先不看股价)

- 优先复用 **`jibenmian-pingfen` 评分**作为质量分(0-5)；无评分时按质量检查表人工打分：
  - 商业模式(复购/网络效应/规模效应/转换成本/平台优势)
  - 收入增长是否持续(5 年 CAGR、增长来源)
  - 毛利率(软件 80%+ vs 硬件 30-50% 分行业看)与营业利润率趋势
  - 自由现金流(FCF 是否增长、FCF 利润率、利润含金量)
- 半导体公司注意区分 Fabless/Foundry/IDM/设备/材料的质量指标差异，不得混用。

### 3. 判断成长空间(未来 5 年)

- 收入：参考行业规模 × 市占率路径，不要只外推当前增速；
- 利润率：改善必须有机制(规模效应/产品结构/成本下降)，并注明兑现时间；
- 把"AI 会改变世界"拆成"增加什么收入→提高多少利润→何时兑现"。

### 4. 选择估值指标

| 公司类型 | 首选指标 |
|---|---|
| 成熟盈利科技股 | PE(对照自身历史区间与同业) |
| 高速成长股 | PEG = PE ÷ 盈利增长率 |
| 暂时亏损/微利 | EV/Sales(需判断未来利润率) |
| 成熟现金牛 | FCF yield |
| 半导体重资产 | EV/EBITDA、PB(周期位置) |

### 5. 运行三维综合模型(批量筛选)

把质量分、最新增速、估值/行情数据整理成 CSV，运行：

```bash
python3 scripts/valuation_model.py assets/example-input.csv --out-dir /tmp/valuation-out
```

- 综合分 = 质量(默认 50%)+ 增长确定性(30%)+ 估值安全边际(20%)，权重可调(`--weights`)；
- 增长分 = 0.5×最新季度营收增速档 + 0.3×三年营收 CAGR 档 + 0.2×扣非增速档；
- 估值分 = 0.4×PEG 档 + 0.3×涨幅透支档 + 0.3×PB 档；**提供 PE/PB 历史分位列时优先用分位**；
- 亏损/微利公司 PE 无意义(标记 note)，估值分基于 PB/涨幅，不得把无意义 PEG 当 0。
- 检查输出：growth_score/valuation_score/total_score 是否合理，PEG 是否被低基数增速误导。

### 6. 个股 DCF 三情景与安全边际

对候选池或重点标的，按 `references/dcf-scenarios.md` 建三情景：

- 悲观/基准/乐观 → 价值区间；
- 当前价格落在区间哪端 = 市场已反映多少乐观预期；
- 安全边际：普通公司 40-50%，优秀公司 20%；"合理价以下 30%"才符合买入纪律。

### 7. 写估值结论

每家公司输出：

1. 质量/增长/估值三维分与综合分(或三情景价值区间)；
2. 选用的估值指标与理由(为何不用其他指标)；
3. 关键假设表(收入增速、利润率、折现率、终值)与敏感度；
4. 合理价格区间 + 当前价格相对区间的位置 + 隐含的预期；
5. 主要风险(竞争/技术替代/需求/利率/估值压缩)；
6. "不构成投资建议"声明。

## 批量横向比较

对一篮子公司(如半导体同业)：

- 用三维模型跑综合分排序，标出**均衡型**(质量×估值×涨幅三佳)、**拐点型**(低估值+增速拐点+未大涨)、**质量强但贵**(需回调到安全边际)、**涨幅透支**(已大涨需验证兑现度)四类；
- 跨公司比较必须同口径(同指标变体、同期、同币种、同复权方式)，否则标 N/C；
- 明确区分"已实现的涨幅"与"未来空间"：过去 1 年涨幅只是预期兑现度的提示，不是未来预测。

## 局限

- 科技股估值高度依赖假设，DCF 的"答案"由假设决定，必须做敏感度与三情景；
- PE/PB 历史分位比绝对值更有意义；未提供分位时以绝对分档为近似；
- 单季同比增速≠年化增速≠一致预期；高增长低基数公司的 PEG 会虚低；
- 成长股估值对利率(折现率)敏感；
- 本 skill 输出分析判断与研究筛选，不构成投资建议、不提供买卖指令。
