# 三维综合评分模型(质量 50% + 增长 30% + 估值 20%)

把"公司质量、增长确定性、估值安全边际"合成一个可批量计算的分数，用于横向比较与候选池筛选。

## 1. 总公式

```
综合分 = Wq × 质量分 + Wg × 增长分 + Wv × 估值分
默认权重: Wq=0.50, Wg=0.30, Wv=0.20(可调)
```

三个子分均为 1-5，与 jibenmian-pingfen 评分同量纲。

## 2. 质量分(Quality)

- **优先**：直接复用 `jibenmian-pingfen` 的评分输出(六维 TTM 诊断总分，0-5)。
- **替代**：按 `valuation-methods.md` 质量检查表人工打 1-5 分。
- 半导体公司注意子行业差异，不得用 Fabless 的指标口径评设备/Foundry。

## 3. 增长确定性分(Growth)

```
增长分 = 0.5 × 营收增速档 + 0.3 × 三年营收CAGR档 + 0.2 × 扣非增速档
```

分档(高好指标，达到下限即进入该档)：

| 指标 | 5分 | 4分 | 3分 | 2分 | 1分 |
|---|---|---|---|---|---|
| 最新季度营收同比% | ≥60 | [40,60) | [20,40) | [5,20) | <5 |
| 三年营收 CAGR% | ≥25 | [15,25) | [8,15) | [0,8) | <0 |
| 最新季度扣非同比% | ≥100 | [50,100) | [20,50) | [0,20) | <0 |

**注意**：
- 缺失值按 1 分处理(不得用高分填补未知)；亏损/扭亏的扣非增速按 `jibenmian-pingfen` 的 turnaround 规则处理(扭亏给 4 分、转亏给 1 分)。
- 单季高增可能不可持续，CAGR 加权 30% 正是为了抑制单季噪声。

## 4. 估值安全边际分(Valuation)

```
估值分 = 0.4 × PEG档 + 0.3 × 涨幅透支档 + 0.3 × PB档
(若提供 PE/PB 历史分位，则估值分 = 0.4×PE分位档 + 0.2×PB分位档 + 0.2×PEG档 + 0.2×涨幅档)
```

分档(低好指标，不超过上限即进入该档)：

| 指标 | 5分 | 4分 | 3分 | 2分 | 1分 |
|---|---|---|---|---|---|
| PEG(=PE÷营收增速) | <1 | [1,2) | [2,3) | [3,4) | ≥4 或 PE 无意义 |
| 一年涨幅% | ≤100 | (100,200] | (200,300] | (300,400] | >400(涨幅已透支) |
| PB | ≤5 | (5,10] | (10,15] | (15,25] | >25 |
| PE 历史分位% | <20 | [20,40) | [40,60) | [60,80) | ≥80 |
| PB 历史分位% | <20 | [20,40) | [40,60) | [60,80) | ≥80 |

**注意**：
- **PE 无意义**的情形(亏损、微利、PE>500)：PEG 档记 2 分并加 note，不得把无意义 PEG 当 0 或高估便宜。
- 低基数高增速会压低 PEG(如扭亏公司营收+719%)，须在结论中提示 PEG 失真。
- "涨幅透支"用的是**已实现**涨幅，只是预期兑现度的提示，不是未来预测。

## 5. 候选池分类(批量比较时)

按综合分与三维结构把标的分为四类：

| 类型 | 特征 | 含义 |
|---|---|---|
| 均衡型 | 质量高 + 估值分较高 + 涨幅低 | "好公司+相对便宜+未透支"，重点研究 |
| 拐点型 | 增速拐点 + 低估值(PB/PEG 低) + 涨幅小 | 需验证增长持续性 |
| 质量强但贵 | 质量/增长满分但 PE/PB 极高 | 只有回调到安全边际才符合策略 |
| 涨幅透支 | 估值分低(已大涨) | 基本面兑现度需后续季报验证，当前价格含大量预期 |

## 6. 脚本

批量计算请用 `scripts/valuation_model.py`，输入 CSV 列：

```
company,quality_score,rev_growth,rev_cagr_3y,nps_growth,pe_ttm,pb,return_1y
```

可选列：`pe_pct,pb_pct`(历史分位 0-100，提供后估值分优先用分位)。缺失列留空即可。

```bash
python3 scripts/valuation_model.py assets/example-input.csv --out-dir /tmp/valuation-out
```

输出：每行附加 `growth_score`、`valuation_score`、`total_score`、`note`(如"PE无意义/低基数PEG")。

## 7. 局限

- 权重与分档阈值为启发式约定，可按风险偏好调整；
- 未提供历史分位时，估值分用绝对值分档近似，结论须标注；
- 模型是筛选工具，不构成投资建议。
