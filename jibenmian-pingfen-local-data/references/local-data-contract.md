# 本地数据契约

## 1. 数据入口

默认根目录：

```text
/home/fss/data/上市公司财务信息
```

必需目录：

| 目录 | 用途 |
|---|---|
| `利润表数据` | 收入、成本、利润、研发费用 |
| `资产负债表数据` | 资产、负债、流动性、权益、商誉 |
| `现金流量表数据` | OCF、长期资产现金支出、销售收现、现金等价物 |
| `财务指标数据` | 扣非净利润、加权 ROE、带息债务、周转天数、折旧摊销 |
| `财务审计意见数据` | FY 审计状态及审计风险筛查 |

文件名必须为完整证券代码，例如 `688981.SH.csv`。读取 UTF-8 BOM。

## 2. FY 选行

对每个 FY：

1. `报告期` 等于当年 12 月 31 日；
2. 存在 `报告期类型` 时必须为 `年报`；
3. 存在 `报告类型/报表类型` 时必须为 `合并报表`；
4. 存在审计意见时，优先选择与审计意见公告日一致的报表行；
5. 同一最终公告日期先选择关键字段最完整的行；
6. 完整度相同但关键字段冲突时失败，不猜测版本。

没有审计意见的 FY 可生成 `unaudited` 事实，但不能把它包装成已审计证据。

## 3. 季度选行与 TTM

支持 `Q1/Q2/Q3`：

| 季度 | 报告期 | 报告期类型 |
|---|---|---|
| Q1 | 3 月 31 日 | `一季报` |
| Q2 | 6 月 30 日 | `半年报` |
| Q3 | 9 月 30 日 | `三季报` |

季度利润表和现金流量表按年初至报告期累计值处理。年度可比流量使用：

```text
TTM = 最近完整 FY + 当前季度累计 - 上年同期季度累计
```

增长率使用当前季度累计值对比上年同期累计值，不使用 TTM 对上一完整 FY。资产、负债、现金、带息债务和权益使用季度末时点。季度事实统一为 `unaudited`。

三年 CAGR 使用最近四个完整 FY；三年现金转换使用最近三个完整 FY。Q4 不单独处理，使用完整 FY。

## 4. 主要字段映射

| 标准事实 | 本地目录/列 |
|---|---|
| `revenue` | 利润表/`营业收入` |
| `operating_cost` | 利润表/`减:营业成本` |
| `net_profit_parent` | 利润表/`净利润(不含少数股东损益)` |
| `net_profit_total` | 利润表/`净利润(含少数股东损益)` |
| `profit_before_tax` | 利润表/`利润总额` |
| `rd_expense` | 利润表/`研发费用` |
| `nps_parent` | 财务指标/`扣非净利润` |
| `roe_weighted_parent` | 财务指标/`加权平均净资产收益率` |
| `interest_bearing_debt` | 财务指标/`带息债务` |
| `inventory_days` | 财务指标/`存货周转天数` |
| `depreciation_amortization` | 财务指标/`折旧与摊销` |
| `operating_cash_flow_raw` | 现金流/`经营活动产生的现金流量净额` |
| `long_term_asset_capex` | 现金流/`购建固定资产、无形资产和其他长期资产支付的现金` |
| `cash_receipts` | 现金流/`销售商品、提供劳务收到的现金` |
| `cash_and_cash_equivalents` | 现金流/`期末现金及现金等价物余额` |
| `total_assets` | 资产负债表/`资产总计` |
| `total_liabilities` | 资产负债表/`负债合计` |
| `current_assets/current_liabilities` | 资产负债表对应合计列 |
| `goodwill` | 资产负债表/`商誉` |
| `equity_parent/equity_total` | 资产负债表不含/含少数股东权益 |

所有原始事实保存相对 `source_file`、`csv_row`、列名和原值。所有计算事实保存公式及依赖 fact IDs。

## 5. 禁止替代

- 不用 `货币资金` 替代现金及现金等价物。
- 不用期末 `研发支出` 替代当期资本化研发投入。
- 不把空白商誉解释为零。
- 不用主营业务产品/地区构成推断客户或供应商集中度。
- 不把业绩预告/快报当作完整 FY 审计事实。
- 不把季度累计值直接与全年阈值比较；先构造 TTM。
- 不用简单乘以 2、4 或 `4/3` 的方式年化季度指标。
- 不从 PDF、旧分析报告或 `caiwu-fenxi` 事实账本回填本地缺口。
- 不把飞书横比的 0–100 分当作本规则评级。

## 6. 可追溯产物

`local-source-manifest.json` 保存实际读取文件及 SHA-256。`local-facts.csv` 和 `score-input.csv` 也各自保存哈希。原始文件变化后必须重新生成整包。
